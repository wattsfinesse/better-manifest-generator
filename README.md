# WATTS Manifest Generator

GitHub Pages-ready static site.

## Files
- `index.html`
- `assets/styles.css`
- `assets/script.js`
- `_config.yml`

## Deploy
1. Push these files to the root of your GitHub repository.
2. Turn on GitHub Pages for the repository.
3. Use the `main` branch root as the publish source.

## Notes
- The site is split into separate HTML, CSS, and JS files.
- Jekyll is enabled through `_config.yml` with the `minima` theme.
